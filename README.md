# Sistema de Agendamento de Consultas - Especificação de Requisitos

## 1. Visão Geral
Este documento especifica os requisitos funcionais e não funcionais do módulo de agendamento.

## 2. Requisitos Funcionais (RF)
- [ ] RF01: O paciente deve conseguir visualizar os horários disponíveis de cada médico.
- [ ] RF02: O sistema deve permitir o agendamento de consultas com confirmação via WhatsApp e e-mail.
- [ ] RF03: O médico deve visualizar sua agenda diária e semanal.

## 3. Requisitos Não Funcionais (RNF)
- RNF01 (Desempenho): O tempo de resposta para busca de horários não deve exceder 2 segundos.
- RNF02 (Segurança): Dados sensíveis de saúde devem estar em conformidade com a LGPD.
